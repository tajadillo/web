# Academia en Caja®

**Sistema Institucional Premium para Academias de Danza y Percusión Afroperuana**

## Descripción

Plataforma web institucional completa para la gestión, promoción y venta de contenidos educativos especializados en música y danza afroperuana. El proyecto integra un sistema de diseño completo, 20 volúmenes educativos, blog, campus virtual y panel administrativo.

## Tecnologías

- **HTML5** semántico con microdatos Schema.org
- **CSS3** con Custom Properties y diseño responsive mobile-first
- **JavaScript** vanilla (ES6+) sin dependencias externas
- **SVG** vectorial para marca y sistema de iconos

## Diseño

- **Sistema de diseño completo** con 15 categorías (Logo, Colores, Tipografía, Iconografía, Botones, Cards, Formularios, Tablas, Alertas, Espaciados, Componentes, Animaciones, Responsive, Accesibilidad, SEO)
- **Paleta cromática**: Negro #000000, Amarillo #FFEA00, Blanco #FFFFFF
- **Paleta extendida**: Dorado #C9A84C, Terracota #B85C3A, Marfil #F5F0E8, Grafito #2C2C2C
- **Tipografía**: Bebas Neue (títulos display), Montserrat (cuerpo y subtítulos)
- **25 iconos vectoriales** inspirados en la cultura afroperuana

## Instalación

1. Clona o descarga el repositorio
2. Abre `index.html` en tu navegador
3. No requiere build tools, compiladores ni dependencias externas

## SEO

- Meta tags completos (title, description, Open Graph, Twitter Cards)
- Breadcrumbs estructurados
- Sitemap XML y robots.txt
- Marcado semántico HTML5
- URLs limpias y optimizadas
