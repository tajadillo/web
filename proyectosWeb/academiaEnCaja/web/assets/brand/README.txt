GENERAR ICONO PNG
Para generar icon-192.png y otros formatos PNG:
1. Abre assets/brand/favicon.svg en cualquier navegador
2. Toma captura o usa herramienta como:
   - https://realfavicongenerator.net/
   - Inkscape: exportar a PNG 192x192
   - ImageMagick: convert favicon.svg -resize 192x192 icon-192.png
